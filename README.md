# Telegram-бот для тематических новостей

Бот читает RSS-ленты выбранных порталов, фильтрует записи по ключевым словам,
не публикует повторы, берёт изображение и краткое описание статьи и отправляет
пост в закрытую группу-модераторскую. После нажатия кнопки «Опубликовать» пост
появляется в канале; «Пропустить» отклоняет его. Постоянно работающий сервер,
платёжный аккаунт и платный API не нужны.

## Что уже умеет

- несколько RSS-источников;
- общие и отдельные для источника ключевые слова;
- стоп-слова;
- ограничение возраста и числа публикаций за один запуск;
- поиск фото в RSS и в `og:image` статьи;
- обязательный перевод материалов Dahua, Tiandy и Shelly на русский;
- предложка с кнопками «Опубликовать» и «Пропустить»;
- публикация одобренного поста в формате «фото + текст», а при проблеме с
  фото — текстом;
- защита от повторной ссылки и почти одинаковых заголовков;
- безопасный предварительный просмотр;
- бесплатный запуск по расписанию через GitHub Actions.

## 1. Настроить источники

В `config.yaml` уже добавлены проверенные RSS-ленты Secuteck, HubiQ,
тематического хаба Хабра, Ferra и iXBT, а также HTML/XML-адаптеры официальных
страниц CTV, Dahua, Tiandy и Shelly. Можно отключить ненужные источники,
добавить другие или изменить ключевые слова. Официальные материалы Dahua,
Tiandy и Shelly автоматически переводятся на русский. Если перевод недоступен,
англоязычный материал не публикуется.

```yaml
sources:
  - name: "Название портала"
    rss_url: "https://portal.example/rss"
    enabled: true
    include_any: []
    exclude: []
    fetch_article: true

topic:
  include_any:
    - "искусственный интеллект"
    - "нейросеть"
  exclude:
    - "реклама"
```

Если `topic.include_any` оставить пустым, бот будет брать все новости.
HTML-страницы без RSS требуют отдельного адаптера под конкретный портал.

## 2. Настроить бесплатный перевод

Используется бесплатный [MyMemory Translation API](https://mymemory.translated.net/doc/spec.php).
Регистрация, банковская карта и отдельный ключ не нужны. Бот отправляет на
перевод только уже отобранные новости и автоматически делит длинное описание
на небольшие части. Если бесплатный лимит сервиса исчерпан или сервис временно
недоступен, англоязычная статья не публикуется.

В `config.yaml` перевод включён только у англоязычных источников:

```yaml
translation:
  provider: "mymemory"
  target_language: "ru"
  required: true
```

## 3. Создать Telegram-бота

1. Откройте официального [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, задайте имя и сохраните выданный токен.
3. Добавьте бота администратором канала с правом публикации сообщений.
4. Для публичного канала `TELEGRAM_CHAT_ID` имеет вид `@channel_name`.
   Для частной группы или канала понадобится числовой идентификатор вида
   `-100...`.
5. Создайте закрытую группу-предложку, добавьте туда бота и отправьте `/id`.
   Ручной режим `discover` покажет её числовой
   `TELEGRAM_MODERATION_CHAT_ID`.

Никогда не помещайте токен в `config.yaml` или репозиторий.

## 4. Проверить локально

Нужен Python 3.11 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install .
.\.venv\Scripts\news-bot --config config.yaml --dry-run
```

Предварительный просмотр ничего не отправляет и не изменяет историю.

Для настоящей проверки задайте переменные только в текущем терминале:

```powershell
$env:TELEGRAM_BOT_TOKEN="токен_из_BotFather"
$env:TELEGRAM_CHAT_ID="@имя_канала"
$env:TELEGRAM_MODERATION_CHAT_ID="-1001234567890"
.\.venv\Scripts\news-bot --config config.yaml --check
.\.venv\Scripts\news-bot --config config.yaml --queue
.\.venv\Scripts\news-bot --config config.yaml --process-moderation
```

## 5. Запустить бесплатно на GitHub

1. Создайте репозиторий GitHub и загрузите в него проект.
2. В `Settings → Secrets and variables → Actions` добавьте три секрета:
   `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` и
   `TELEGRAM_MODERATION_CHAT_ID`.
3. В `Settings → Actions → General → Workflow permissions` разрешите
   `Read and write permissions`. Это нужно только для сохранения
   `data/state.json` и `data/moderation.json`, чтобы бот не дублировал посты
   и помнил решения модератора.
4. Откройте вкладку `Actions`, выберите `Telegram news moderation`, нажмите
   `Run workflow` и запустите режим `check`.

Расписание находится в `.github/workflows/news-bot.yml`. Новые материалы
собираются каждый час на 17-й минуте, а кнопки проверяются каждые 5 минут.
Запуск может задерживаться: GitHub Actions не гарантирует точность cron до
минуты. До одобрения модератором бот ничего не публикует в канале.

## Ограничения первой версии

- Бот не переписывает материал нейросетью: он делает аккуратную выжимку из
  описания источника и переводит её. Это не добавляет выдуманных фактов.
- Бесплатный перевод зависит от доступности и лимитов публичного MyMemory API.
- Для сайта без RSS понадобится небольшой отдельный парсер.
- Перед публикацией проверяйте правила источников и право использовать их
  изображения и текст. Ссылка и имя источника включены по умолчанию.
